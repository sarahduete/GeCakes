# 🍰 GeCakes

**Site institucional para confeitaria**

Projeto desenvolvido para apresentar uma confeitaria por meio de um site com identidade visual própria, destacando a marca e seus produtos.

🔗 **[Acessar o site](https://gecakes.netlify.app/)**

---

## 📖 Sobre o projeto

A ideia do GeCakes surgiu da proposta de criar uma presença digital para uma confeitaria. O objetivo era desenvolver um site que transmitisse a identidade da marca e apresentasse os produtos de maneira organizada e atrativa.

## 💻 Como foi desenvolvido

O desenvolvimento começou com a definição da identidade visual. Trabalhei com uma proposta delicada, utilizando elementos e cores que combinassem com o universo da confeitaria.

Em seguida, comecei a estruturar as páginas, pensando na melhor forma de apresentar a marca e organizar as informações sobre os produtos.

Depois, trabalhei na estilização do site, ajustando cores, fontes, imagens e espaçamentos para criar uma composição visual harmoniosa.

Durante o processo, procurei manter uma identidade consistente em todas as partes do projeto, dando atenção principalmente à apresentação dos produtos e à experiência de navegação.

## ⚙️ Características do projeto

- Apresentação da marca.
- Exibição dos produtos.
- Identidade visual personalizada.
- Organização das informações da confeitaria.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
